확인한 사실

- 학교 공지 "강의실 대여 신청서(양식)"는 학사지원팀이 2019년 4월 3일에 올린 글이다. 상상관·탐구관·미래관 강의실을 쓰려면 먼저 우촌관 3층 학사운영팀 8~9번 창구를 찾아가거나 760-4219로 전화해 사용 가능 여부를 확인하고, 신청서를 출력해 학과 사무실을 거친 뒤 학사운영팀에 제출하고, 이후 캡스 상황실과 기자재실에도 제출하라고 안내한다. (https://www.hansung.ac.kr/bbs/hansung/2195/217052/artclView.do)
- 양식 안에는 학사운영팀 확인란과 지도교수 확인(인)란이 있고, 유의사항 1번은 학사운영팀 확인 후 진리관·탐구관 신청서는 탐구관 기자재실(탐구관 2층)에, 미래관·상상관 신청서는 상상관 기자재실(상상관 3층)에 제출하라고 적혀 있다.
- 빈강의실 현황 페이지 하단에는 "강의실은 학사운영팀에 사용여부 확인 후, IT인프라팀에 신청서 제출"이라고 적혀 있어, 공지·양식·현황 페이지가 안내하는 최종 제출처가 서로 다르다.
- 빈강의실 현황은 미래관/우촌관과 탐구관/진리관이 서로 다른 화면으로 나뉘어 있고, 교시 단위로만 보여 주며, 그 화면에서 바로 신청할 수 없다.

확인한 사실

- 학생복지팀 "학내잔류 신청안내" 페이지(최종 수정 2026.01.23): 최소 5인 이상의 잔류만 허가하고, 1주일 단위로 신청한다. 신청서는 최소 하루 전까지, 부득이하면 당일 낮 12시 전까지 학생복지팀에 방문 제출해 사용 승인을 받고, 승인받은 신청서 사본을 교내 캡스 상황실에 제출한다. 문의 02-760-4221. (https://www.hansung.ac.kr/hansung/6139/subview.do)
- 양식에는 기간·시간·목적·건물명·호실·소속·학번·연락처와 함께 지도교수 확인(인), 학과장(전공주임) 확인(인)이 필요하고, 잔류자 명단은 최소 5인 이상이어야 한다.
- 양식 유의사항: 1주일 이상 연속 잔류는 주 단위로 다시 작성한다, 하계·동계에는 냉난방 컨트롤러를 확인한다(중앙관제실 760-4416), 잔류 신청을 해도 음주 후 입실은 안 되고 23시 이후에는 개방하지 않는다.
- 허가서 제출처: ADT캡스 종합상황실(연구관 B1층, 760-4238).
- 야간 잔류가 시작되는 기준 시각은 팀 확인 기준 22시 이후로 정리했다. 학교 페이지에는 시작 시각이 적혀 있지 않다.

확인한 사실 (https://www.hansung.ac.kr/cncschool/4182/subview.do, 2026-11-13)

- 세미나실은 101호부터 113호까지 13개이고, 달력에는 빈 시간이 아니라 이미 예약된 시간만 표시된다. 예를 들어 11월 2일 칸 하나에 예약 23건이 호실별로 나열되어 있어, 원하는 시간에 빈 방을 찾으려면 학생이 13개 방의 예약 목록을 직접 비교해야 한다.
- 방 하나씩 보려면 호실 선택 상자에서 호실을 고르고 검색을 눌러야 하고, 달력은 화면이 좁으면 좌우로 밀어야 보인다(안내 문구가 화면을 가린다).
- 로그인하지 않은 상태에서 신청하기를 누르면 "손님은(는) 예약 할 수 없습니다"라는 문구만 나온다. 로그인 후 신청 화면에서 호실과 시간을 고르는 과정은 팀원 계정으로 직접 캡처해 보완한다.
