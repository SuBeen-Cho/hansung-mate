# Demo document assets

- classroom.pdf / overnight.pdf: user-supplied blank Hansung University official form PDFs, paired with the HWP originals inspected on 2026-09-28. These are blank templates, not student documents. The application adds a conspicuous DEMO statement and does not generate institutional stamps.
- NotoSansKR-Regular.woff: static weight 400, Latin/Hangul subset derived using fontTools from Google Fonts Noto Sans KR variable font.
- NotoSansKR-Regular.ttf.gz: gzip-compressed static TrueType face for PDF embedding. Composed Hangul/ASCII coverage; shaping tables removed for deterministic form text.
- OFL.txt: font license included with the source font.

Font source: https://github.com/google/fonts/tree/main/ofl/notosanskr
PDF rendering uses the original page as the background; user inputs are drawn at reviewed coordinates. Template versions must be reviewed before replacement.

The HWP originals, private transcripts, signatures entered by users, and runtime application PDFs are not stored in source control. Generated demo test PDFs are local review outputs only.
